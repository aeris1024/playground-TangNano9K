# Analog2PDM 電圧選択版の検討（2026-11-16）

正式版として[006_analog2pdm_select](../designs/006_analog2pdm_select/README.md)を追加しました。
以下は検討時の記録です。正式版はADC受信をBCLK取り込みへ変更し、setup/hold違反0件でビルドしています。
MODE開放（3.3 V）でSRAM転送が正常終了し、ユーザーがA/Bの音声を確認しました。
1.8 V側も音声を確認しました。未選択3.3 V側へのMCHStreamerクロック同時供給時にA側の音切れがあり、
その供給を止めると症状が出なくなったとの実機報告があります。同時供給時の原因は未解決です。
最新の結果は[検証記録](verification/006_analog2pdm_select.json)を参照してください。

## 合意した条件

電源OFFで外付けスイッチを変更し、再投入して選択します。PDM端子は1.8 V用・3.3 V用の2組です。
A/Bのクロック独立性、48 kHz、音声処理、PWM音量LEDは維持します。
一つのバンクの電源や同じ端子のI/O規格を動的に切り替える構成ではありません。

## 推奨する最小構成

- 1本のMODE入力で両系統の電圧ポートをまとめて選択。
- 基板27 MHzでMODEを2段同期し、起動約10 ms後に選択を固定。以後のスイッチ操作は無視。
- 選択確定までは基準クロックを停止状態にし、PLLと音声処理を起動させない。
- 確定後、各系統の選択したクロックで周波数判定、PLL LOCK、250 ms待ちを実施。
- 音声処理とPLLはA/B各1組を共用。DATA用DDRセルだけ電圧ごとに用意（合計4個）。
- 非選択DATAはLow固定。停止中の選択DATAも既存回路同様Lowにする。
- 非選択側は無音PDMではなくLow固定なので、非選択の受信機で正常な音声を取得できる仕様ではない。
- 電圧の自動検出・動作中の切り替え・A/B別々の電圧選択は初版に含めない。

## 端子案

USB-Cを上にした部品面から見て右側ヘッダーの位置です。

| 信号 | 1.8 V端子 | 3.3 V端子 |
|---|---|---|
| CLK A | J6-6 / FPGA82 | J6-1 / FPGA63 |
| DATA A | J6-7 / FPGA81 | J6-19 / FPGA48 |
| CLK B | J6-8 / FPGA80 | J6-20 / FPGA49 |
| DATA B | J6-9 / FPGA79 | J6-21 / FPGA31 |

1.8 V側はJ6の1.8 V端子範囲の下端4本にまとめます。4本ともバンク3です。
既存005のJ6-3〜6は変更せず、電圧選択版でのみ上記配置を使う計画です。

MODEはJ6-22 / FPGA32（3.3 Vバンク）の空き入力を使う候補です。

```text
MODE (J6-22 / FPGA32) ─ [1kΩ 任意] ─ スイッチ ─ GND (J6-23)
        │
  FPGA内部プルアップ（3.3 V）
```

スイッチ開放=3.3 V、閉=1.8 Vです。以前の外付けプルダウン案から選択極性を変更します。
CSTで `IO_PORT "mode_select" IO_TYPE=LVCMOS33 PULL_MODE=UP BANK_VCCIO=3.3;` とします。
Gowin GPIOは内部プルアップ／プルダウンを選択できるため、外付け10kΩは不要です。
短い基板内配線ならスイッチとGNDの直結で使用できます。
1kΩの直列抵抗は必須ではありませんが、別デザインで誤ってGPIOをHigh出力にした場合の
GND短絡電流を抑えるため、取り付けられるなら残すことを推奨します。ESD保護を保証する部品ではありません。
長い配線やノイズが多い環境では外付けプルアップを追加する余地を残します。
これはユーザー回路の選択GPIOであり、FPGAのコンフィグレーション用MODEピンではありません。
スイッチ変更時は基板電源をOFFにします。起動後の内部プルアップが有効な状態で設定を読みます。
再設定したい場合は再投入またはFPGA再コンフィグレーションが必要です。
ADCとLEDの端子は変更せず、PCM1808は引き続き3.3 V信号・5 V/3.3 V電源を使います。

## Hi-Z案について

初案では非選択DATAをHi-Zにしました。シミュレーションでは動作しましたが、
ODDRCのQ0を通常のfabric制御TBUFに接続する構成がGowinのCK0011で拒否されました。
ODDRCにはTX/Q1の専用OEN経路がありますが、クロック停止時や初期値を含む追加設計が必要です。
今回の最小案はLow固定とし、Hi-Z動作を保証する案ではありません。

## 試作で確認したこと

一時プロジェクトはbuild/feasibility_voltage_switchです。正式なデザインは未登録です。
003/005と実機のSRAM/Flashは変更していません。

- 外部クロック停止側を含め、起動1.8 V/3.3 Vの各モードで既存005の全体シミュレーションPASS。
- 非選択DATAのLow固定と、選択固定後のスイッチ変更が無視されることを確認。
- 全回路の合成・配置配線は搭載資源内で成立。
- Logic 6501/8640、Register 3187/6693、BSRAM12/26、DSP10/10、PLL2/2、PRIMARY5/8、IOLOGIC4/97。
- MUX後に両モードの派生クロックを定義し、A/B非同期とモード間排他を指定。
- 最終試作のsetup違反0件、hold違反2件。両方ともADC DOUT→I2S受信shiftレジスター経路。
- 一般配線によるクロック接続などの警告は残る。

**この試作はまだタイミングを満たした実機用デザインではありません。**
正式実装ではADCデータのlaunch/captureクロック、分周クロックの位相、受信側のクロックイネーブルを考慮して、
制約と受信タイミングを検証し、hold違反を解消してから書き込みます。違反を単にfalse pathで隠しません。

### J6-6〜9・内部プルアップ案の追加検証（2026-11-16）

doctorでツールとGW1NR-9C（ID=0x1100481B）の接続を確認し、既存005の自己判定シミュレーションはPASSでした。
上記4端子とMODEのPULL_MODE=UPだけを変更した試作をbuild/feasibility_voltage_switch内に作成しました。
build_lower.tcl / switch_lower.cstを使ったprobe_switch_lowerは合成・配置配線・bitstream生成まで正常終了しました。
pin.htmlで82/81/80/79がバンク3のLVCMOS18、MODE=32がLVCMOS33・UPで実装されていることを確認しました。
2基のPLLも使用できています。Logic6501/8640、PLL2/2、setup違反0件、hold違反2件です。
したがって端子の移動と内部プルアップ設定は配置配線上成立しますが、先のADC入力タイミング課題は残ります。
内部プルアップの実機電圧、スイッチ起動判定、新端子での音声はまだ実機未確認です。SRAM/Flashへの書き込みはしていません。

## 実装する場合の手順

1. 003/005を残して別の電圧選択デザインを作成。
2. 起動ラッチと出力停止条件を自己判定し、選択側だけのクロックでも起動できることを確認。
3. 両モードのI/O・クロック・CDCを解析し、setup/hold違反0件まで修正。
4. 電源OFFでスイッチ位置を決め、SRAMで各モードのLOCK・音声・出力電圧・停止復帰を確認。
5. 必要なら最後にFlash保存と、スイッチ位置ごとの電源再投入を確認。
