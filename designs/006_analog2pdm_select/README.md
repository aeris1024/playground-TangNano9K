# 006 Analog2PDM voltage selection

PCM1808基板2枚の4chを、独立した2系統のステレオPDMへ変換します。
PDM側の1.8 V／3.3 Vを外付けスイッチで選ぶ別デザインです。
003（3.3 V）、005（1.8 V）の配線とデザインは変更しません。

## 電源OFFで選択

MODEはJ6-22 / FPGA32です。内部プルアップを使用します。

```text
MODE (J6-22) ─ [1 kΩ 任意・推奨] ─ スイッチ ─ GND (J6-23)
```

| スイッチ | MODE | 使用するPDM端子 |
|---|---|---|
| 開放・未接続 | High | 3.3 V |
| GNDへ接続 | Low | 1.8 V |

外付け10 kΩや3.3 Vへの配線は不要です。直列1 kΩは別デザインでGPIOを誤って出力にした場合の短絡電流を抑えます。
MODEは電源投入／再コンフィグレーションから約10 ms後に取り込み、それ以後の変更は無視します。
電源OFFで配線と選択を変更してください。SRAMへの書き込みでも設定を取り直します。

## PDM配線

USB-Cを上にした部品面から見て右側がJ6です。USB側から1〜24と数えます。

| 信号 | 1.8 V端子 | 3.3 V端子 |
|---|---|---|
| CLK A 入力 | J6-6 / FPGA82 | J6-1 / FPGA63 |
| DATA A 出力 | J6-7 / FPGA81 | J6-19 / FPGA48 |
| CLK B 入力 | J6-8 / FPGA80 | J6-20 / FPGA49 |
| DATA B 出力 | J6-9 / FPGA79 | J6-21 / FPGA31 |
| 共通GND | J6-23等 | J6-23等 |

1.8 V側は固定1.8 Vバンク、3.3 V側は固定3.3 Vバンクです。同じ端子の電圧を切り替える機能ではありません。
1.8 V端子へ3.3 V信号を接続しないでください。非選択DATAはLow固定です（Hi-Zや無音PDMではありません）。
外部クロックは各系統とも3.072 MHz、fs=48 kHz専用です。A/Bは独立です。
選択されていない側のクロックは不要です。両系統で同じ電圧モードを選択します。
LCDコネクタと共有する端子なので、LCDは併用しません。

## ADC・LED

ADC側は従来の3.3 V信号のままです。PCM1808の電源は5 Vと3.3 V、MD1/MD0/FMTはLowです。

| 信号 | A FPGAピン | B FPGAピン |
|---|---:|---:|
| MCLK / SCK | 25 | 29 |
| BCLK / BCK | 26 | 30 |
| LRCLK / LRC | 27 | 33 |
| DOUT / OUT | 28 | 34 |

LED1/4はPLL LOCK、LED2/5は音声処理開始、LED3/6はPWM音量表示です。異常時は点滅を優先します。
PDMはL=立ち下がり取り込み、R=立ち上がり取り込みで、各系統のSWAP_EDGESパラメーターで交換できます。
音声処理は005と同じ−6 dBヘッドルーム、FIR×8、CIC×8、2次ΔΣです。

## ADC受信タイミング

ADC DOUTをBCLK立ち上がりのレジスターで取り込み、1 MCLK後にI2Sシフトレジスターへ渡します。
従来のMCLKクロックイネーブルで外部DOUTを直接取り込む方式から変更しました。
BCLK→取り込み、BCLK→MCLKの内部転送とも通常のsetup/hold解析を行います。
ADC経路にfalse pathやmulticycleの例外は追加しません。
入力遅延はBCLK立ち下がり基準で最大50 ns／最小−10 nsの基板配線を含む予算です。
外部配線・相手機器がこの予算とPDM出力の20 ns要求に収まることは実測で別途確認します。

## 操作・検証

```powershell
.\fpga.ps1 doctor
.\fpga.ps1 sim 006_analog2pdm_select
.\fpga.ps1 build 006_analog2pdm_select
.\fpga.ps1 program 006_analog2pdm_select
```

自己判定テストは1.8 V／3.3 Vの両起動モード、内部プルアップを模した開放入力、選択の起動後固定、
非選択DATA Low、未選択側への異なる周波数の同時クロック供給、I2S符号・1 bit遅延・L/R、PDM密度とエッジ交換、±1000 ppmの独立クロック、
A/Bの停止・復帰、2.8224 MHzの拒否、PWMと異常点滅を検証します。
検証結果と実機観測の範囲は[検証記録](../../docs/verification/006_analog2pdm_select.json)に分けて記録します。
Flashへの保存は今回行いません。

## 実機確認の状況（2026-11-16）

3.3 V側はユーザーがLED1/2/4/5の点灯とA/Bの正常な音声を確認しました。
1.8 V側も音声は確認できましたが、その後A側でLED2が頻繁に落ち、LED3も同時に明滅し、音切れが出るとの報告があります。
LED1のPLL LOCKは目視では安定していました。
その後、未選択の3.3 V側に供給していたMCHStreamerのクロックを止めると、症状が出なくなったとユーザーが確認しました。
使用する電圧側だけにクロックを供給する運用をユーザーと合意しました。
両電圧でA/Bの音声疎通を実機確認済みです。未選択側のクロック停止は現時点の運用上の回避策です。
これはRTL上の必須条件ではなく、両コネクタ同時クロック供給での実機安定性は未解決です。
同時供給の自己判定シミュレーションは両モードでPASSしましたが、外部波形・配線による結合と内部クロック配線の影響は区別できていません。
シミュレーション／STA合格だけで実機の安定動作を保証する結果とはしていません。
