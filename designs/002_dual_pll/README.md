# 002_dual_pll

指定した2本の外部クロックから、独立した2基のrPLLを使ってADC用クロックを生成する検証用デザインです。
Analog2PDM実装の前提となる配置配線を確認するために用意しています。

| 信号 | 系統AのFPGA物理ピン | 系統BのFPGA物理ピン |
|---|---:|---:|
| 基準クロック入力 | 63 | 49 |
| MCLK出力 | 25 | 29 |
| BCLK出力 | 26 | 30 |
| LRCLK出力 | 27 | 33 |

公称入力は3.072 MHzです。MCLKは12.288 MHz、BCLKは3.072 MHz、LRCLKは48 kHzです。
PLLは`IDIV_SEL=0`、`FBDIV_SEL=3`、`ODIV_SEL=64`を使用します。
基板の27 MHzで入力周波数と停止を監視し、停止から約8 µsで該当系統だけをリセットします。
再開時は周波数判定、LOCK、同期リセット解除、250 ms待ちを経てREADYになります。

LED1/2/3はAのLOCK/READY/クロック有効、LED4/5/6はBの同じ状態です。
`003_analog2pdm`のLED3/6は異常表示なので、意味が異なります。

```powershell
.\fpga.ps1 doctor
.\fpga.ps1 sim 002_dual_pll
.\fpga.ps1 build 002_dual_pll
```

シミュレーションは、位相差、±1000 ppm、4倍比、A/Bそれぞれの停止・復帰を検証します。
待ち時間だけを短縮し、PLLは機能モデルを使用します。ジッタや実機のLOCKを保証するテストではありません。

配置配線では2/2基のrPLLを同時に使用できることを確認しました。
外部機器が未配線のため、実機での逓倍比とLOCKは未確認です。

## 右側ヘッダーへの集約（2026-11-13）

USB-Cを上にした部品面から見て右側のJ6にPDM信号をまとめました。
AのCLKはJ6-1（FPGAピン63）、BのCLKはJ6-20（ピン49）です。
ピン49は一般GPIOのためPR1014のクロック配線警告が残ります。
変更後のシミュレーション・配置配線は成功し、setup/hold違反は0件です。実機LOCK・波形は未確認です。
